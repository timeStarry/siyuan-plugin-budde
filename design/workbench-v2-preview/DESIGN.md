# Budde V2 静态页面设计规范

状态：已按用户确认的 36px 契约应用到整页及同源组件样张；范围仅为当前离线草图，不代表正式插件已迁移。

## 1. 设计原则与边界

- 保留已选定的黑白灰、按类型看板、420px 阅读侧栏、阶段路径与当前位置。
- 不修改正式插件、核心、存储和现有可交互原型；不添加真实业务交互。
- 一名主代理写入；复核只读；不安装依赖、不启动服务器。
- 当前是桌面插件草图。窄分屏验证不等于移动端支持。
- 规范先定义用途，再定义值；不能通过局部覆盖让同类控件产生不同高度。

## 2. Token 层级与唯一来源

当前页面内已存在 token 层；本次在其基础上补齐，而不另建一套平行 UI 库。

1. **基础层 `--p-*`**：中性色阶、空间、字号/行高、字重、圆角、尺寸、时长。
2. **语义层 `--c-*` / `--font-*` / `--line-*` / `--weight-*` / `--s-*`**：表面、文字、分隔、交互状态、排版角色和空间角色。
3. **组件层 `--control-*` / `--layout-*` / `--path-*`**：控件与布局的公开尺寸契约。

唯一来源：页面中的 `budde-tokens` 样式块。组件定义独立位于 `budde-components` 样式块，页面布局位于 `budde-layout`。组件样张复用相同样式块；导出的 CSS 从这些块生成，禁止手工维护第二份色值或尺寸。

## 3. 中性色与语义

| 用途 | 浅色 | 深色 |
|---|---|---|
| 画布 | #F5F5F5 | #1B1B1B |
| 内容表面 | #FFFFFF | #232323 |
| 次级表面 | #EDEDED | #2D2D2D |
| 主文字 | #262626 | #E9E9E9 |
| 次文字 | #666666 | #B0B0B0 |
| 装饰分隔 | #DEDEDE | #434343 |
| 交互控件边界 | #8A8A8A | #7D7D7D |
| 强调 / 反色文字 | #262626 / #FFFFFF | #EBEBEB / #1B1B1B |
| 选中表面 | #E9E9E9 | #353535 |
| 悬停表面 | #EDEDED | #303030 |
| 按下表面 | #E0E0E0 | #3B3B3B |
| 关注提示文字 | #595959 | #C2C2C2 |
| 遮罩 | 黑色 14% | 黑色 36% |

- 宿主字体、正文、表面、装饰边界仍可适配思源对应变量；控件强调使用正文/背景对色，不引入宿主彩色 primary。
- 非文本交互边界与相邻背景的目标对比度 ≥3:1；正文与元信息 ≥4.5:1。装饰分隔线不冒充控件边界。
- 需复查、暂停、完成靠图标和文字区分，不依赖颜色。未实现的错误反馈不得伪装成业务已接入。

## 4. 排版

继承宿主字体，回退到系统字体，不使用远程字体。页面不设置字距压缩补丁。

| 角色 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| title | 20 / 28px | 600 | 类型标题、事项标题 |
| brand | 18 / 24px | 600 | Budde 标识文字 |
| body | 14 / 24px | 400 | 阅读正文、快速记录提示 |
| control | 13 / 20px | 500 | 所有常规按钮、导航、类型、搜索入口 |
| label | 13 / 20px | 500 | 卡片标题、阶段/章节标题 |
| meta | 12 / 16px | 400 | 计数、状态、路径注释、预览说明 |

字重仅使用 400 / 500 / 600；计数采用等宽数字。

## 5. 间距、图标、边界与圆角

- 空间基准：4px；允许的常规值为 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48px。
- 控件图文间距 8px；按钮组间距 8px；紧密元信息间距 4px。
- 页面水平边距 24px；区域间距 24px；阅读面内边距 24px；阅读章节间距 24px。
- 圆角：控件 6px、内容卡 8px、状态标记 4px、圆形节点 50%。
- 边框 1px；焦点环 2px、偏移 2px。无外框控件预留透明边框以避免状态跳动。
- **所有界面图标 16×16px**，统一 24px viewBox、1.75 线宽、圆端点；品牌标识独立为 24×24px。
- 不再使用 13 / 14 / 18px 的局部图标尺寸。阶段节点不是图标，按独立几何 token 绘制。

## 6. 控件尺寸与变体

### 常规操作控件

| 属性 | 规范 |
|---|---|
| 固定高度 | **36px**，包含边框，不允许局部 min-height 补丁 |
| 文本按钮 | 水平内边距 12px，最小宽度 64px；宽度随内容增长 |
| 主要按钮 | 同样 36px 高，最小宽度 80px；用反色而不是增高表示主要级别 |
| 图标按钮 | **36×36px**，图标 16px，padding 0 |
| 搜索 / 类型入口 | 同为 36px 高、13/20px 字体、16px 图标 |
| 侧栏类型项 | 36px 高，撑满导航宽度；计数右对齐 |
| 禁止事项 | 按区域把按钮改为 26/28/32/40px；用文字行高撑高度；图标按钮变成长方形 |

- 变体：primary（主要）、outline（次要）、ghost（低干扰）；变体不改变尺寸、字排或圆角。
- 页面映射：记录为 primary；编辑与搜索为 outline；顶部导航、归档、类型选择、管理入口、阅读底栏及主题切换为 ghost。
- 选中导航/类型使用同一选中表面与 600 字重；不改变盒模型。
- 可用状态：default、hover、pressed、focus-visible、disabled、loading。禁用不响应点击且不参与 Tab；loading 使用 `aria-busy` 并禁用，保留原本尺寸。组件样张展示这些规则，不新增页面业务流程。
- 键盘焦点使用统一焦点环，不能只依靠 hover；减少动态效果时停用过渡。

### 内容型入口（不是小按钮）

- 事项卡：最小高度 80px，内边距 12px，随内容增长；不得强制 36px 或固定高度截掉说明。
- 笔记入口：最小高度 56px，标题/角色两行；统一 hover、focus、pressed 反馈。
- 两者在组件样张与验收中明确分类；不能把例外扩大到其他操作按钮。

## 7. 布局契约

| 项目 | 值 |
|---|---|
| 顶栏 | 64px |
| 快速记录区 / 记录容器 | 80px / 56px |
| 看板与阅读工具栏 | 56px |
| 阅读操作栏 | 至少 64px |
| 预览说明栏 | 48px，容纳完整 36px 主题按钮 |
| 类型索引 / 区域间距 | 144px / 24px |
| 阅读侧栏 | 420px |
| 看板列最小宽度 / 列间距 | 184px / 12px |
| 路径节点 / 每步最小宽度 | 20px / 80px |

顶栏品牌占据类型索引同宽，主导航与看板内容左缘对齐。响应式只改变布局，不偷偷缩小控件。

- `<1200px`：详情覆盖全高度，遮罩覆盖锁定区域，预览主题按钮移入同一焦点循环。
- `<720px`：详情全宽。关闭详情后，导航/看板在各自内部滚动，不使页面横向溢出。
- 正文可滚动；工具栏、操作栏不被 flex 压缩。长标题、计数、窄分屏不得挤扁图标按钮。
- `<360px` 极窄面板仅将详情水平内边距由 24px 降为 16px、隐藏工具栏装饰图标；不改变控件尺寸。

## 8. 动效

- 控件颜色/边框反馈：120ms，禁止 `transition:all`。
- 用户主动展开面板：160ms，使用已有 ease-out；不加入入场编排。
- pressed 通过表面改变反馈，不做按钮缩放或位移，防止视觉基线跳动。
- `prefers-reduced-motion:reduce` 时取消动画与过渡。

## 9. 验收与交付

- 自动测量所有常规操作按钮实际高度 36px，所有图标按钮为 36×36px；检查字体/行高、图标尺寸、焦点、hover/pressed、禁用和 loading。
- 对浅深主题及 1440 / 1024 / 720 / 480 宽度重复检查；增加窄分屏关闭详情后的布局检查。
- 保留已有静态边界、阶段语义、键盘焦点、宿主变量探针、无外部请求与对比度检查。
- 交付完整离线页面、同源组件样张、规范、可复用 CSS 与截图；不宣称已完成真实思源主题/宿主兼容性验收。
