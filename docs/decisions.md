# Budde alpha.1 开发决定

日期：2026-11-11。需求来源：思源 `20261111001236-5io3spm`。

- 工程位于 `D:/Project/budde`，产品与工程代号统一为 Budde，插件包名 `siyuan-plugin-budde`。
- 目标为用户当前的思源 3.4.1 桌面端，使用兼容的 SiYuan SDK 1.1.5，不依赖新版内核插件。
- 采用轻量 TypeScript DOM 界面与构建工具，不引入独立应用框架。
- 池子默认显示未归档事项；显式“开始推进”后进入看板。完成由阶段属性表达，暂停和归档保留原阶段。
- 阶段排序不改变初始阶段或完成属性。删除非空阶段必须迁移，包括归档事项；非空类型不允许直接删除。
- 事项数据使用插件自有 JSON；同机文件锁下读取、版本检查、写入，避免只加版本字段却没有协调写入。
- 幂等创建记录与事项一起持久化，alpha.1 不自动清理。未来若引入清理，需明确新作用域及过期约定。
- 复查按推进后的最近进展时间计算，默认 14 天；浏览不刷新。UI 若尚未提供关闭配置，则不宣称相关配置已完成。
- alpha.1 不支持跨设备并发或离线合并。桌面多窗口须通过独立存储实例验证，不将内存队列当成跨窗口锁。
- 首次交付优先完成已有笔记关联；主动创建文档、用户导入和外部 AI 适配后续实现。不得把 alpha.1 宣称为全部需求已验收。
