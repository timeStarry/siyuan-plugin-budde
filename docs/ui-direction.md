# Budde 工作台方向

用户在思源阅读、写作时随手记下一个标题，之后回来看哪些值得推进。主焦点是标题输入，而非统计。

- 领域：萌芽、留存、展开、路径、下一步、笔记关联。
- 色彩世界：纸面、石墨、淡墨、嫩芽绿、思源主题选中色。实际界面继承宿主主题，不固定浅色背景。
- 识别方式：池子保留标题，看板按类型展开，下一步以一行文字跟随事项。统计收成一条简短状态带。
- 避免：巨大数字卡片、给每种类型涂彩虹色、为每条想法自动展开大表单。
- 布局：轻量页签，直接记录入口，内容区和按需打开的详情栏。类型设置藏入原生对话框。
- 层级：20px/600 页名，14px/500 事项标题，12px/400 次要信息；系统字体继承思源以融入宿主。输入、按钮、卡片使用语义变量及 4px 基础间距，主要控制高度 40px。
- 深度：平面布局和柔和完整边框，不使用装饰阴影；输入稍低一层，详情稍高一层。
- 状态：原生按钮/输入/选择框，完整焦点、禁用、错误、加载、空态。拖动只做便捷入口，阶段选择器提供等效操作。
- 草稿：刷新不会替换未保存详情；过期保存必须提示重新读取并明确放弃草稿。

第一版不包含独立应用或聊天，不制作营销式首页、图片和动画。产品只在保存完成后展示成功状态。
