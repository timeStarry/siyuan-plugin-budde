# Budde 0.1.0-alpha.1 验证记录

日期：2026-11-11。当前目标宿主为思源 3.4.1 Windows 桌面端。

## 已验证

- `pnpm check`：TypeScript 检查、18 项行为与存储测试、插件构建通过。
- 并发测试覆盖独立存储实例、两个独立进程的 48 次提交、5 轮各 32 实例的锁交接压力。
- 测试覆盖数据损坏保留、写入失败、不确定锁保守停止、失效主锁恢复、幂等创建、旧版本冲突、阶段删除迁移、导出后的核心数据恢复。
- 独立审查发现“创建后迁移事项并删除原类型会破坏原请求重试”的问题，已修复并加入回归测试。
- Windows 独占打开可能出现 delete-pending 竞争，已增加有界短重试及同 renderer 锁交接队列，最终完整检查通过。
- `pnpm test:plugin`：按安装版思源的 CommonJS 加载方式模拟运行，Node 内置模块、页签、命令、顶部入口注册和卸载通过。不写入真实工作空间数据。
- `pnpm test:ui`：本机 Edge 隔离浏览器通过 11 组场景，涵盖标题记录、推进、阶段拖放、草稿冲突、笔记关联、暂停归档、生命周期设置、设置冲突、导出及响应丢失重试。浏览器无运行时错误。
- 桌面、390px 窄窗口及深色主题截图已检查；窄窗口没有页面外层横向溢出，看板列允许内部横向滚动。

交互测试使用内存存储和可控笔记桥；真实文件存储由独立进程测试覆盖。开发截图和测试导出位于忽略提交的 `artifacts/qa/`，不包含用户真实事项。

## 尚未验证／尚未实现

- 尚未在用户当前思源窗口内启用并走测，插件加载检查为宿主加载器模拟，不代表原生窗口验收完成。
- 未验证 macOS、Linux 实机，不支持移动端、浏览器或跨设备并发合并。
- alpha.1 支持关联已有笔记，尚未提供主动创建笔记、用户导入界面、永久删除或外部 AI 适配。
- 待复查采用 14 天默认规则，尚未提供单独的关闭配置。
- 本版本不是全部正式需求的完成声明，下一步应优先完成真实思源窗口走测和试用反馈。
