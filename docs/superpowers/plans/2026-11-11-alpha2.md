# Budde Alpha.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver 0.1.0-alpha.2 contextual lifecycle configuration and refined offline desktop interactions without weakening transactional or host safety.

**Architecture:** Keep the existing service/controller/React-view boundaries. Add a pure core type-presentation/template catalog, reuse protected settings and detail controllers for contextual commands, and use instance-owned React components for the picker, inline stage form, motion and HUD.

**Tech Stack:** Existing React/TypeScript/Tailwind/shadcn/Radix/Lucide/Motion/dnd-kit; no new runtime dependencies or network assets.

**Spec:** [Approved design](../specs/2026-11-11-alpha2-design.md). User approved vertical timeline and direct execution.

## Global Constraints

- schemaVersion: 1; preserve export envelope, expectedVersion/expectedRevision, request identity, file lock and rollback.
- One Lead writer; optional reviewers read-only; no install/restart/commit/merge/push.
- Controls 36px; light/dark; tabular numbers; instance portals/focus/events; IME and draft retention.
- Ordinary outline icons 1.5px; hover 150ms ease-out; tabs 180ms cubic-bezier(0.22,1,0.36,1); reduced motion.
- New template IDs generated atomically; metadata read fallback never mutates legacy states.
- Execute the five phases below in order, not concurrently. Each phase begins with a failing behavioral test and ends with its focused checks.

## File Map

- `src/core/type-config.ts` (new): curated names/Chinese keywords, colors, single-Emoji validation, stage templates; no React or host import.
- `src/core/types.ts`, `service.ts`: optional metadata and template commands/validation; unchanged lock/export boundaries.
- `src/ui/type-presentation.tsx` (new): shared TypeIcon/color presentation and offline picker, no storage calls.
- `settings.ts`, `settings-view.tsx`: contextual open target and protected metadata editor.
- `collection-view.tsx`, `workbench-view.tsx`, `index.ts`: sidebar context, column commands/Ghost Column, navigation and root shortcuts.
- `detail-view.tsx`, `detail.ts`: vertical stage buttons, protected apply, dirty/guard state, success feedback.
- `components/icons.tsx`, shared menu primitives, tokens/styles: outline strokes and bounded reusable material/motion rules.
- `tests/type-config.test.ts` (new), `scripts/verify-alpha2.mjs` (new): core and production-browser regressions.
- Existing verify scripts: update only superseded management entry points/path assertions; retain other protections.
- package/plugin metadata, PRODUCT/README/design contracts/validation notes: alpha.2 version and accurate scope.
