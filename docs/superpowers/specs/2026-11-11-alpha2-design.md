# Budde 0.1.0-alpha.2 — 架构交互与消费级质感综合升级

## 已确认方向与边界

用户选择「垂直时间轴，直接执行」，按五阶段顺序实施，不再逐项询问。保持现有小芽、离线 Quicksand 字标、Zinc 中性工作台与 36px 控件；这是现有产品的交互和材质升级，不是另起视觉世界。唯一写入者为 Lead。使用现有 linked worktree，不安装到真实思源、不重启、不改变启用状态、不提交/合并/推送。

## 一、类型模型

- `ItemType.icon?: string`：36 个精选 Lucide 名称之一或一个 Emoji 字素；`color?: "default" | "blue" | "emerald" | "amber" | "violet" | "rose"`。
- 展示字段缺省时在渲染层回退中性 Shapes 线框图标；不修改旧快照、不补写字段、不改变 `schemaVersion: 1`。
- create/update 命令添加可选展示字段；update 缺省表示保留，`null` 表示恢复缺省。仅配置命令增加 revision，事项 version 不因展示字段更新改变。
- 创建类型可原子选用 basic/article/software/travel/blank 阶段模板；不传模板沿用旧的「想法/完成」。模板只影响新类型，ID 独立生成。
- 保留旧 `type.delete` 被引用时 IN_USE 的安全规则；本轮「迁移删除」用于阶段，继续覆盖归档事项并原子增加相关事项版本。
- JSON 导出信封不变；可选字段自然随 data.types 导出，无新增导出版本。

## 二、配置入口与选择器

- 全局右上角菜单仅导出 JSON、重新读取。
- 看板类型侧栏标题提供 +，新增类型；类型行独立编辑按钮 hover/focus 显示，直接打开该类型的配置表单。小屏也可键盘访问。
- 看板最右端虚线 Ghost Column：点击进入名称输入，Enter 创建、Esc 取消；保持 IME 和提交锁，失败保留文字，revision 冲突不自动重放命令。
- 列标题 hover/focus 菜单：重命名、完成属性、左/右移动、迁移删除。重命名/删除复用受保护的设置编辑器，并直接定位相关阶段；重排与完成切换使用现有命令及 revision。
- 类型配置保留初始阶段选择，新增图标/Emoji 双标签选择器、中文关键词搜索、六色方案、实时预览。所有图标静态导入打包，无请求。
- 表单与控制器分离；不因预览或普通输入重新挂载整张表单，避免 IME、selection 和焦点丢失。失败、冲突、脏关闭、异步销毁继续遵循原保护。

## 三、详情阶段路径

- 使用可完整换行的垂直时间轴，不截断名称，不使用横向滚动。每阶段按钮至少 36px 高，长名称可自然增高，不压缩命中区；普通控件仍固定 36px。
- 展示当前位置、完成属性；顺序不暗示执行历史、累计进度或完成百分比。
- 阶段按钮可前后跳转，调用同一 `DraftSession` apply 通路，维持 expectedVersion/失败反馈；不自动推进尚未推进的事项。
- 当前阶段指示器使用实例与事项隔离的 layoutId；reduce-motion 关闭移动。

## 四、质感与反馈

- 普通图标 fill=none、currentColor、1.5px、圆端点；品牌继续原资产；活跃状态只允许小面积透明底。
- 工作区/列/卡片/详情层次清晰，边框 1px；暗色卡片顶部 `inset 0 1px 0 rgba(255,255,255,0.06)`；菜单/HUD 半透明并 blur，保持文字对比。
- 卡片次要操作与手柄仅 hover/focus-within 显示，150ms ease-out；键盘仍可操作，触摸设备显式显示。
- 拖动原位置虚线占位，overlay scale 1.02、有限抬升阴影，不虚构持久排序。
- 顶部导航胶囊 180ms cubic-bezier(0.22,1,0.36,1)；详情轻滑入；脏保存按钮轻呼吸；未保存关闭保护触发一次弹性摇动，reduce-motion 禁用。
- root 内 C 聚焦快速输入；忽略 editable、IME、修饰键、repeat、开放弹层及其它实例。输入旁显示 Enter 提示；Esc 经 requestClose 关闭干净详情，脏详情仍走保护。
- 暂停/恢复、复查、归档/恢复仅在成功后显示本实例底部居中短暂 HUD；错误保留现有错误反馈，不伪装成功；销毁清 timer。
