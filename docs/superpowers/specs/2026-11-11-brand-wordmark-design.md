# Budde 品牌字标微调

## 已确认的视觉选择

用户在三款对比中选择右侧 **Quicksand SemiBold 600**，评价为“符合预期”。原小芽造型保留，只微调英文 Budde 字标。

参考：[三款对比图](../../../artifacts/design/brand-wordmark-20261111/comparison.png)；[离线对比页](../../../artifacts/design/brand-wordmark-20261111/comparison.html)。

## 方案比较

- 原版：识别度不变，但不满足圆笔画微调诉求。
- Nunito 600：较克制、接近原版；用户未选择。
- **Quicksand 600：更圆润、几何感更明确；用户选定，以右侧预览为外观基准。**

## 已批准接入范围

这是小范围品牌修整，不是新一轮界面重构。

- 工作台左上角采用原小芽 + Quicksand 600 字标；以原图校准小芽的圆头笔画、双叶和直立茎，正式资产不直接放大低分辨率截图。
- 思源入口和工作台共享同一小芽品牌资产，避免入口与页面使用两种不同造型。普通功能图标继续使用 Lucide；品牌资产为单独例外。
- 字标仅影响 Budde 品牌，不更换正文、中文、按钮或卡片字体，不改变布局、主题和业务行为。
- 字标使用本地随包品牌资源，字重固定为 600，不依赖用户安装字体、在线请求或 CDN。优先选择不会增加运行时依赖、可稳定复现预览字形的输出方式。
- 保留 Quicksand 官方版权及 SIL OFL 1.1 许可说明；不把已核对字体授权表述为名称/商标等一切权利的绝对零风险保证。
- 校验浅色/深色、1440×900 与 1280×800 标题栏的字形、对齐、对比度及无溢出；运行类型、业务、UI/宿主与发布校验。
- 通过后备份当前发布包，再覆盖本地 alpha.1 ZIP 及其校验文件；用户真实思源插件目录、数据和启用配置不动，不重启思源，不提交、合并或推送。

## 依据与约束

- 视觉基准为用户提供的小芽截图和已选右侧预览，不采用当前通用 Lucide Sprout 替代原标志。
- 现有 [UI 规范](../../../ui-design-system.md) 其余条款保留；品牌例外在用户确认接入范围后落入规范。
- [Quicksand 官方许可](https://raw.githubusercontent.com/google/fonts/main/ofl/quicksand/OFL.txt)；[已下载许可副本](../../../artifacts/design/brand-wordmark-20261111/fonts/Quicksand-OFL.txt)。

视觉选择已批准；用户随后明确选择“接入并更新 ZIP”，批准上述接入、入口一致性、校验、备份及覆盖本地发布包范围。真实思源安装仍不在授权范围内。
